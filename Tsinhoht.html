游戏内容

Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → 勾选 repo → 生成 → 复制 ghp_ 开头的字符串。默认仅在当前浏览器会话保存；勾选后会长期明文保存在本机浏览器中，共用或不受信任设备请勿勾选。

注意：Token 是你的 GitHub 密钥，只用于向你的仓库提交文件，请勿外泄。发布后刷新如看不到更新请 Ctrl+F5 强刷。

评论功能配置（Supabase 免费版）

访客填昵称、邮箱、内容即可评论，支持回复。数据存在你的 Supabase 免费项目（500MB，评论量随便用）。配置步骤见仓库 README「评论功能」一节：注册 supabase.com → 新建项目 → SQL Editor 粘贴建表语句运行 → 复制 3 个值填到下面。

Supabase 浏览器端禁止使用 secret 私钥，所以删除评论改用自编密钥：SQL 里设置一个，这里填同一个，即可删除评论。只存你浏览器，绝不写入网站。

推荐：上面「发布帖子」页签填好 GitHub Token（勾选 repo + workflow 权限）后，本站长回复会自动触发仓库 Actions 用你的 QQ 邮箱发邮件给用户（见 README「站长回复邮件通知」）。此框仅供旧版 Supabase 通道使用：部署 notify-reply 函数并配好 SMTP 后，把 Notify-Secret 填这里（只存本浏览器）。两种方式都不填则回复照常发布、只是不发邮件。

保存配置会提交 site.json 到仓库，随后所有帖子（含已有的）自动带上评论区，2-3 分钟后生效。管理密钥填好后：本页签可批量删除；打开任意帖子，评论下方也会出现删除按钮。
