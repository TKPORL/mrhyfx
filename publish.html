发布中心

把幕布导出的 HTML 粘贴到下方，点发布即可自动上传到 GitHub，随后 GitHub Actions 会自动生成首页与每日页面，1-2 分钟后全站更新。

1. 填写信息

输入本期标题（如：8.2）和幕布导出的 HTML 内容。

2. 填入密钥

使用你的 GitHub Token（需要 repo 权限）。只在你的浏览器中处理，存于本机。

3. 点击发布

文件自动提交到仓库，Actions 自动生成首页并部署，等待即可。

创建地址：github.com/settings/tokens → Generate new token → 勾选 repo，过期时间建议 90 天。

即保存的文件名，注意与往期不要重名。

注意：Token 是你的 GitHub 密钥，只用于向你的仓库提交文件，请勿外泄。发布后首次访问请强制刷新（Ctrl+F5）以避免浏览器缓存。
