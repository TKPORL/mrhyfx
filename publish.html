游戏内容

Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → 勾选 repo → 生成 → 复制 ghp_ 开头的字符串。Token 和仓库名只在本浏览器自动保存（localStorage），下次打开无需再填。

注意：Token 是你的 GitHub 密钥，只用于向你的仓库提交文件，请勿外泄。发布后刷新如看不到更新请 Ctrl+F5 强刷。

帖子管理

删除帖子会同时删除它的全部图片（assets 目录）、标题和游戏数配置，然后自动重新生成首页。

评论功能配置（Supabase 免费版）

访客填昵称、邮箱、内容即可评论，支持回复。数据存在你的 Supabase 免费项目（500MB，评论量随便用）。配置步骤见仓库 README「评论功能」一节：注册 supabase.com → 新建项目 → SQL Editor 粘贴建表语句运行 → 复制 3 个值填到下面。

保存配置会提交 site.json 到仓库，随后所有帖子（含已有的）自动带上评论区，2-3 分钟后生效。私钥填好后：本页签可批量删除；打开任意帖子，评论下方也会出现删除按钮。
