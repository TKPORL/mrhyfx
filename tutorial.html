02解压密码

站内约三分之一的资源带密码
先搞清楚：帖子里的「介绍」怎么打开
游戏帖里的介绍不是直接铺在页面上的。进帖子后，点一下游戏封面图，完整介绍才会弹出来 —— 图片下面那行小字「点击图片查看完整介绍」说的就是这个，很多人没注意到。
解压码就写在弹出来的这段介绍里。所以找密码的第一步永远是：进帖子 → 点图片 → 把介绍打开。
密码在介绍里的哪个位置
不固定，不同帖子的写法不一样，这三个位置都出现过：
最上面　标题下面那一两行就写「解压码：xxx」。
中间　夹在版本说明、更新内容里。
最下面　写完介绍和下载说明之后才写密码。
复制了还提示密码错误
别多复制　密码后面常跟着【备注】之类的说明，只复制密码本身。
别带空格　用鼠标拖动选中容易带上前后空格，粘进去先把空格删掉。
全角半角　中文输入法打出来的符号和英文的不是同一个，能复制就别手打。
页面会把大部分「解压码：xxx」自动做成一个「解压码」按钮，点一下直接复制。但这个功能没覆盖全部帖子（不少老帖子没转换成功），没看到按钮不代表没有密码，回介绍里往下翻找文字。

03解压时提示出错

压缩包损坏 / CRC 错误先对照帖子里写的大小，确认文件下全了；下全了还报错，多半是网盘在线解压导致的，下载到本地再解
报毒 / exe 被删这类游戏被误报很常见：关掉杀毒实时防护，或把游戏文件夹加信任，再重新解压
路径太长 / 解压到一半失败把压缩包挪到短路径再解，例如 D:\game\，别放在桌面深处
文件名全是乱码解压软件里把文件名编码选成日文（Shift-JIS）；还不行就先转区再解压
提示密码错误看上面第 02 节「解压密码」，重点检查有没有多复制备注或者带上空格

04解压怎么解

先装一个解压工具，主流就这四个
WinRAR　电脑端首选，rar / zip / 7z 都能开，装完右键就有解压菜单。前往下载
ZArchiver Pro　安卓端首选，改后缀、解分卷都在这里面。前往下载
RAR-mod 版　安卓端另一个选择，界面更简单。前往下载
lz4 解压工具　只用来解 .lz4 文件，普通解压软件打不开这种。前往下载
改后缀之前，先让电脑把后缀显示出来，不然你改的其实不是真后缀（会变成 xxx.mp4.txt）：Win10 文件资源管理器 → 顶部「查看」→ 勾选「文件扩展名」；Win11 →「查看」→「显示」→ 勾选「文件扩展名」。手机不用设置，ZArchiver 里长按文件 → 重命名即可。
exe多数直接双击解压；个别是伪装后缀，改成 zip 或 rar 再解
tar直接解压
分卷全部分卷放同一个文件夹，只解压 part1（第一卷）
psd、jpg后缀改成 rar 后解压
00、txt后缀改成 rar 后解压
mp4后缀改成 zip 或 rar 后解压（先下载到本地，别在线解压）
7zWinRAR 直接能开；打不开就装 7-Zip
lz4普通解压软件打不开，要用专门的 lz4 工具，在上面「先装一个解压工具」里

手机（安卓）怎么解压
流程和电脑一样，换成在 ZArchiver 里操作：
解压　打开 ZArchiver 找到压缩包，点它 →「解压到当前目录」。
改后缀　mp4 / exe 这类伪装文件：长按 → 重命名，改成 zip 或 rar，再点开解压。
分卷　所有分卷放同一个文件夹，点第一个解压。
安装　解压出 apk 直接点开安装；解压出数据包文件夹的，按游戏说明放到指定目录。
手机管家报毒多为误报，加信任即可；别用网盘在线解压，先下载到手机再操作。

05解压完了打不开

乱码 / 双击没反应 / 闪退
这是「非 Unicode 程序语言」不是日语导致的，三种办法任选其一：
Locale Emulator（推荐）　解压后运行 LEInstaller.exe 注册右键菜单，之后右键游戏 exe → Locale Emulator → Run in Japanese。工具在 游戏工具 · 其他工具 里。
NTLEA　另一款转区工具，用法类似。
改系统区域　控制面板 → 区域 →「管理」→ 更改系统区域设置 →「非 Unicode 程序语言」设为日语（日本）→ 重启（一劳永逸）。
转区工具行为特殊，杀软可能误报，从本站镜像或官方源下载即可。
缺 xxx.dll / 0xc000007b / 提示缺少运行库
多数是缺运行库：装 Visual C++ 运行库（x86 和 x64 都装），必要时补 DirectX 与 .NET，都在 游戏工具 · 运行库 里。0xc000007b 基本都是补齐 VC++ 运行库就能解决。
文字变方框 / 存档找不到
缺字　系统缺日文字体：装 MS Gothic / Meiryo，或转区运行。
存档　通常在游戏目录下的 save 文件夹，或「我的文档」、%APPDATA% 里以品牌命名的目录。
