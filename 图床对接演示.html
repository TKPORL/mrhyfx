图床对接演示 方案一：全局开关，二选一

这不是截图假演示 —— 下面的「真实测试」按钮会真的往你的图床传一张图。密码只存在你这台电脑的浏览器里，本文件不含任何密码。

1图床设置（以后会出现在后台 GitHub Token 下方，长这样）

规则只有一条：这两格留空 = 一切照旧走 GitHub；填上 = 新发布的图全部自动传图床。不用开关按钮，填没填就是开关。

测试图由本页面现场生成（不是本地文件、不占空间），上传成功后会在下面直接显示它从图床加载回来的样子 —— 传 + 取，一条链路全验。

2发帖时是什么体验

发布界面和你现在一模一样，唯一的区别是每张图片卡下面多了行小字，告诉你这批图会去哪：

没配图床时（现状）GitHub 模式

封面图片（二选一：上传文件 或 粘贴 URL）
📁 选择图片 已选 3 张
图片将保存到 GitHub 仓库 assets 目录，经 jsDelivr 显示

配了图床后（新）图床模式

封面图片（二选一：上传文件 或 粘贴 URL）
📁 选择图片 已选 3 张
图片将自动上传到你的图床 tsinho-cloudflare-imgbed.pages.dev，不再进入 GitHub 仓库

点「发布」后自动完成：选图 → 逐张传图床 → 拿回链接 → 写进帖子。你要做的操作和现在完全一样，一张图都不用手动搬。想反悔？把设置清空，立刻回到 GitHub 模式，两边互不影响。

3这个演示 ≠ 最终改造范围

看完满意的话，真改动就三个文件、四处：

① 后台配置区：加图床地址 + 密码两格（就是上面这块）
② 后台上传函数：填了图床 → 走图床；没填 → 走现在的 GitHub，自动判断
③ 首页生成脚本 gen.js：豁免图床链接，别把它们又下载回 GitHub 仓库
④ 首页封面提取：兼容图床直链（不然新帖在首页没缩略图）

网站里已有的几千张老图一张都不动，照常显示。老图搬家是以后的独立步骤，随时可做可不做。
